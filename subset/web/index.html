Podešavanja

Standard: A zeleno = mix in, B žuto = prvi drop/refren, C crveno = mix out + memory cue na svakoj frazi.
Klub: + D narandžasto = drugi drop, E ljubičasto = break.

Rekordbox – jednom podesi

  1. Rekordbox → Preferences → Advanced → Database → rekordbox xml → Imported Library → izaberi
  2. View → Layout → uključi rekordbox xml u levom meniju.
  3. Posle svakog exporta: u levom meniju rekordbox xml → osveži → desni klik na set → Import To Collection / Import Playlist.
